# GitHub CRM Project

This is a Dockerized Nest.js project using PostgreSQL and Prisma.

## 🛠 Requirements

- pnpm
- Docker
- Docker Compose


## 🚀 Getting Started

1. **Clone the repository**

   ```bash
   git clone https://github.com/w1nteRR/github-crm-backend.git

2. **Start the project**

   ```bash
   docker-compose up --build

3. **Access the app**

   ```
   API: http://localhost:3000
	•	PostgreSQL: available at localhost:5432 (user: postgres, password: postgres)


4. **Clone frontend app**
    
    ```
   https://github.com/w1nteRR/github-crm-frontend.git

5. **Start the project**

   ```
   pnpm run dev

6. **Access the app**

   ```
   http://localhost:5173/
